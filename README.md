# AltSTU Schedule

Виджет для KDE Plasma 6, который показывает расписание занятий АлтГТУ прямо на рабочем столе. Сам скачивает расписание с сайта вуза, разбирает его и держит копию на диске, поэтому работает и без интернета.

> Скриншот будет добавлен позже (`docs/screenshot.png`).

## Возможности

- Две группы во вкладках — например, своя и параллельная.
- Расписание на несколько дней вперёд, сегодняшний день и текущая пара подсвечены.
- Для каждой пары: время, предмет, тип занятия (лекция, практика, лабораторная), подгруппа, аудитория, преподаватель.
- Отметки «разово» и «экзамен/зачёт» для занятий вне обычной сетки.
- Автообновление по таймеру (по умолчанию раз в час) и кнопка ручного обновления.
- Кэш на диске: если сайт недоступен, показывается последняя сохранённая версия с пометкой «кэш».
- Запасной режим: можно сохранить страницы расписания в папку, и виджет прочитает их вместо сайта.
- Настройки: группы, частота обновления, сколько дней показывать, показ субботы и воскресенья, путь к Python.

## Установка

Нужны KDE Plasma 6 и Python 3 (только стандартная библиотека, ничего ставить не нужно).

```bash
git clone https://github.com/vladb1588/altstu-schedule-widget.git
cd altstu-schedule-widget
kpackagetool6 -t Plasma/Applet -i .
```

Обновить после `git pull`:

```bash
kpackagetool6 -t Plasma/Applet -u .
```

Удалить:

```bash
kpackagetool6 -t Plasma/Applet -r com.local.altstu.schedule
```

После установки: правый клик по рабочему столу → «Добавить виджеты» → AltSTU Schedule.

`plasmapkg2` из Plasma 5 здесь не подойдёт: виджет написан под API Plasma 6.

## Настройка группы

Номер группы — это число из адреса страницы мобильного расписания: `https://www.altstu.ru/m/s/<id>/`. Открой расписание своей группы на сайте, скопируй число и вставь его в настройках виджета вместе с названием группы.

## Как это работает

```
altstu.ru/m/s/<id>/  →  fetch.py  →  JSON  →  main.qml
                           │
                           └→ ~/.cache/altstu-schedule/<id>.json (кэш)
```

1. **Парсер** (`contents/scripts/fetch.py`) скачивает HTML-страницу расписания через `urllib` (с заголовком User-Agent, без него сайт отвечает 403) и разбирает её регулярными выражениями: недели, дни, пары, тип занятия, подгруппа, аудитория, преподаватель.
2. Результат печатается в stdout одной строкой JSON и сохраняется в кэш `~/.cache/altstu-schedule/`. Запись атомарная (через временный файл), поэтому кэш не ломается при обрыве.
3. Если сайт не ответил или изменилась вёрстка, парсер отдаёт кэш с пометкой `stale` и текстом ошибки.
4. **Виджет** (`contents/ui/main.qml`) запускает парсер через `Plasma5Support.DataSource` (движок `executable`), получает JSON и рисует список дней. Таймеры отвечают за автообновление и за подсветку текущей пары.

Парсер можно запустить отдельно, например для отладки:

```bash
python3 contents/scripts/fetch.py 2000020600            # с сайта
python3 contents/scripts/fetch.py --mock 2000020600     # тестовые данные без сети
python3 contents/scripts/fetch.py --localdir ~/rasp 2000020600   # из сохранённого ~/rasp/2000020600.html
```

## Структура

| Файл | Что это |
|---|---|
| `metadata.json` | описание пакета для Plasma |
| `contents/ui/main.qml` | интерфейс виджета |
| `contents/ui/configGeneral.qml` | окно настроек |
| `contents/config/main.xml` | параметры и значения по умолчанию |
| `contents/scripts/fetch.py` | парсер сайта и кэш |
